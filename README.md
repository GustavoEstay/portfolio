# gustavo-estay-portfolio

Personal portfolio of **Gustavo Estay**, Software Engineer at Mercado Libre (React, TypeScript, AI-driven product engineering).

Built with Next.js 15 (App Router, fully static), React 19, Tailwind CSS 4 and strict TypeScript. Lint, format, typecheck and build run in GitHub Actions on every push.

```bash
npm install
npm run dev   # http://localhost:3000
npm run ci    # lint + format check + typecheck + build
```

Deployed on Vercel.
